Fechario は、期限のあるもの（保証、車検、保険、証明書、サブスクリプション、使用期限・消費期限）を記録し、期限が来る前に通知を受け取るための、JR Soft（以下「私たち」）のアプリです。

1. 概要

  • 記録した内容と写真は、お使いのスマートフォンの中に残ります。アカウントも登録もなく、記録した内容や写真を受け取るサーバーを私たちは一切持っていません。
  • このアプリには Google AdMob の広告が表示されます。そのため、Google の SDK が独自にデバイスの一部のデータを収集します（第4項を参照）。
  • 日付の読み取りと商品の切り抜きは、Google ML Kit がスマートフォン内で行います。写真や文字がスマートフォンの外に出ることはありませんが、SDK は利用に関する技術的なデータを Google に送信します（第4項を参照）。
  • 私たちは、独自の分析ツールを一切使用していません。
  • 私たちが受け取るのは、ご自身がメールで送ってくださった内容だけです。

3. 法的根拠

  • ご依頼いただいたサービスの提供（EU 一般データ保護規則（GDPR）art. 6.1.b）：記録した内容の保存、ご自身が選んだ写真の読み取りと切り抜き、通知のスケジュール設定。いずれもスマートフォン内で行います。
  • 正当な利益（art. 6.1.f）：
  • ML Kit と Google の SDK が、動作し、その動作を測定し、不具合を修正するために送信する技術的なデータ（第4項を参照）
  • お送りいただいたメールへの返信
  • 同意（art. 6.1.a）。欧州経済領域（EEA）、英国、スイスで、Google のフォームを通じてお願いしています。対象は次のとおりです。
  • 広告 SDK がスマートフォンに情報を保存したり、スマートフォンの情報を読み取ったりすること
  • パーソナライズド広告を表示すること 同意されない場合、Google は、パーソナライズされていない制限付きの広告を表示することがあります。その効果測定と不正防止については、Google とそのパートナーが正当な利益に基づいて行っており、これには同じフォームで異議を申し立てることができます。

4. 広告（Google AdMob）と第三者の SDK

広告。 このアプリは、広告を表示し、同意をお願いするために、Google Mobile Ads SDK（AdMob）と Google のユーザー メッセージング プラットフォーム（UMP）を使用しています。これらの SDK は、広告の表示と効果測定、分析、不正防止のために、次のデータを独自に収集し、Google と共有します。 - IP アドレス（ここからおおよその位置情報が推定されます） - デバイスの識別子：広告 ID と app set ID - アプリや広告での操作（起動やタップなど） - 診断データ（アプリと SDK のパフォーマンス）

このアプリが、記録した内容を広告のリクエストに含めることはありません。

詳しくは https://policies.google.com/technologies/partner-sites をご覧ください。

正確な位置情報。 広告の同意メッセージは、Google がすべての広告パートナー共通の文面で表示するため、正確な位置情報について触れています。このアプリには位置情報の権限がなく、GPS の位置情報を SDK に渡すこともありません。Google によると、同社の広告 SDK が使うのは、IP アドレスから推定されるおおよその位置情報だけです。この利用は「オプションを管理」で拒否できます。

Google ML Kit。 写真の文字を読み取り、ご希望の場合は商品を背景から切り離します。いずれもスマートフォン内で行います。画像や文字がスマートフォンの外に出ることはありません。診断と利用状況の分析のために、SDK は次のデータを暗号化して Google に送信します。 - デバイスのデータ（メーカー、機種、Android のバージョン）とアプリのデータ（パッケージ名とバージョン） - このインストールの識別子 - 商品の切り抜きの場合は、Google Play services を経由するため、デバイスの識別子も - パフォーマンスの指標、画像の形式とサイズ、エラーコード

Google によると、これらのデータを第三者に渡すことはありません。切り抜きのモデルは、この機能を使うかどうかにかかわらず、アプリのインストール時に Google Play services がダウンロードします。

Firebase Remote Config。 アプリに組み込まれていますが、無効になっています。有効にならない限り、何も送信しません。いずれ有効にする場合は、このポリシーでその旨をお知らせします。

Google Play。 「アプリを評価」は、Google Play の評価機能を使用します。この機能には Google Play 独自の規約が適用されます。

5. 国際的なデータ移転

Google LLC は、同社の SDK が収集したデータを米国で処理することがあります。Google LLC は、EU-米国データプライバシーフレームワーク（Data Privacy Framework）、その英国拡張、およびスイス-米国データプライバシーフレームワークに参加しており、さらに標準契約条項も使用しています。

私たちのメールは Google（Gmail）が提供しており、同じ保護措置が適用されます。

6. 同意の撤回とデータの管理

  • 広告：アプリの 設定 → 広告のプライバシー設定（法律で求められる地域、つまり EEA、英国、スイスで表示されます）。ここで、同意したときと同じくらい簡単に、同意を撤回したり、正当な利益に異議を申し立てたりできます。また、スマートフォンの Google の設定で、広告 ID をリセットまたは削除することもできます。
  • 通知：スマートフォンの通知設定でオフにするか、項目ごとに通知を外してください。
  • データ：各項目を詳細画面から削除するか、アプリをアンインストールしてください。すべてのデータがスマートフォンから消えます。

7. バックアップと機種変更

設定 → バックアップを保存 では、データと写真を含む .zip ファイルを作成できます。また、スプレッドシートに書き出す（CSV） では、記録した項目の一覧表を作成できます。どちらもご自身が選んだ場所に保存されます（たとえば、ご自身のストレージや個人のクラウド。クラウドの場合は、そのサービスの規約が適用されます）。私たちがこれらのファイルを受け取ることはありません。

このアプリのデータについては、Android のクラウドバックアップ（Google アカウントのバックアップ）を無効にしています。データは一切アップロードされません。Android は再インストールのために、インストールしていたアプリの一覧をアカウントに保存しますが、この一覧は Google が管理しており、アプリのデータは含まれません。

新しいスマートフォンの設定時に、古いスマートフォンからデータを直接コピーした場合（ケーブルの有無を問わず）、アプリのデータ（記録した項目、その写真、設定）が新しいスマートフォンに移ることがあります。この転送はご自身が依頼し、Android が自身のツールまたはスマートフォンのメーカーのツールを使い、それぞれの条件に従って行います。Android のドキュメントによると、データはサーバーを経由せずにスマートフォン間で転送されます。私たちのサーバーを経由することは一切ありません。転送はご自身が Android の機能を使って行うもので、JR Soft がデータを受け取ることはありません。

転送が行われるかどうかは Android のバージョンとメーカーによって異なり（Android 8 以前では行われません）、保証することはできません。古いスマートフォンを使わずに Google アカウントのバックアップから新しいスマートフォンを設定した場合、このアプリのデータはそのバックアップに含まれていないため、戻りません。

古いスマートフォンでしか意味のないもの（設定済みの通知、SDK の識別子、広告に関するご自身の選択など）は転送されません。新しいスマートフォンでは、アプリが通知をあらためて設定し、広告についての選択をもう一度お尋ねします。

8. 未成年者

このアプリは大人を対象としており、16 歳未満の方向けではありません。パーソナライズド広告には同意が必要ですが、EU では、この年齢未満の未成年者はご自身で同意することができません（GDPR art. 8。スペインでは 14 歳未満：個人データ保護及びデジタル権利の保障に関するスペインの組織法〔LOPDGDD〕art. 7）。

9. 保存期間

  • 記録した内容は、削除するかアプリをアンインストールするまで、スマートフォンに保存されます。
  • お送りいただいたメールは、返信に必要な期間、最長で最後の返信から 1 年間保存します。
  • Google の SDK が収集するデータは、Google のポリシーに従って保存されます。

アクセス、訂正、消去、異議申立て、処理の制限、データポータビリティの各権利は、私たちにご連絡いただくことで行使できます。私たちは記録した内容を受け取らないため、これらの権利のほとんどは、アプリで直接行使できます（書き出し、編集、削除）。SDK が収集するデータについては、Google が https://myaccount.google.com と https://policies.google.com/privacy で対応します。

私たちがデータを適切に取り扱っていないとお考えの場合は、スペインデータ保護庁（AEPD、www.aepd.es）、またはお住まいの国、お勤めの国、問題が発生した国のデータ保護機関に苦情を申し立てることができます。
