# Documentos legales de Fechario

Política de privacidad de la aplicación **Fechario** (Android, `com.jrsoft.recordatorio`),
que guarda las cosas que vencen y avisa antes.

Este repositorio existe solo para servir esos documentos por HTTPS con una URL pública
y estable (https://demual.github.io/fechario-legal/), que es requisito de Google Play y del mensaje de consentimiento de
AdMob. **No contiene el código de la aplicación.**

La versión de referencia es la española; las demás son traducciones de la misma
versión y llevan su misma fecha. La App abre la del idioma del móvil (la inglesa si no
está entre estos). Se generan todas a la vez desde el proyecto de la App
(`app/tool/build_legal.py`), así que no se editan a mano aquí.

Se publica con GitHub Pages desde la rama `main`. El historial de commits sirve además
como registro de qué decía la política en cada momento.
